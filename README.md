# Tide (潮汐) 🌊
> *"日程如潮水般有规律地起落，顺应时间的流淌。"*
**Tide** 是一款极简、优雅、隐私优先的跨平台本地日程规划与提醒工具。我们剥离繁杂的社交与冗余功能，为你打造一个纯净、专注的环境，让你从容掌控每一天的潮起潮落。
---
## ✨ 核心功能
### 📅 智能日程编排
点击主界面右上角的 `+` 新建计划，支持灵活的循环策略：
- **单次/特定日期**：最多可选 10 个特定日期，适合不规律事件（如就诊、纪念日）。
- **每日循环**：适合习惯养成（如早起喝水、阅读）。
- **每周特定日**：按星期精准执行（如每周一、三、五健身）。
---
### ⏰ 毫秒级防丢失通知引擎（Android 专项优化）
针对国内安卓定制系统的严格限制，Tide 采用以下技术保障通知准时送达：
- 使用 `USE_EXACT_ALARM` 精确闹钟权限
- 自动时区探测与动态校准
- 支持提前 1 分钟至 24 小时的自定义提醒
> **适用场景**：Vivo (OriginOS)、小米 (HyperOS/MIUI)、华为 (HarmonyOS) 等系统。
---
### 🔄 绝对私有的 GitHub 云同步
无需注册账号，不依赖第三方中心化服务器，数据完全由你掌控。
**配置步骤：**
1. 点击主界面左上角头像
2. 填入你的 **GitHub 私有仓库链接** 和 **Personal Access Token**（需 `repo` 权限）
3. 点击顶部“云同步”图标
**冲突处理：**
当本地与云端数据冲突时，Tide 会弹出可视化面板，供你选择：
- 保留本地
- 拉取云端
---
### 🎨 沉浸式个性化与防溢出排版
- **壁纸切换**：点击顶部 `壁纸` 图标，支持本地相册图片或网络高清图源。
- **极简模式**：点击顶部 `日历/列表` 按钮，在“今日待办”与“全部跨期计划”间无缝切换。
---
## ⚠️ 跨平台兼容性说明
Tide 致力于全平台部署，但受限于各操作系统底层机制差异，当前支持情况如下：
### 📱 Android（主战场）
| 状态 | 说明 |
|------|------|
| ✅ 完美支持 | 瞬间通知与定时预警均正常工作 |
**已知问题：**  
部分定制 ROM（如 Vivo、小米、华为）可能强杀后台闹钟进程。
**解决方案：**  
请在系统设置中为 Tide 开启以下权限：
- ✅ 允许自启动
- ✅ 允许后台高耗电（无限制）
- ✅ 在多任务界面下拉加锁
---
### 🐧 Linux
| 状态 | 说明 |
|------|------|
| ⚠️ 基础可用 | 数据同步与核心功能正常运行，**定时通知受限** |
**已知限制：**  
Linux 桌面环境缺乏统一的定时唤醒机制。`flutter_local_notifications` 插件未实现 `zonedSchedule` 方法，定时通知会被静默拦截，但手动触发的即时弹窗可正常工作。
---
### 🪟 Windows
| 状态 | 说明 |
|------|------|
| ❓ 未经充分测试 | 可能存在兼容性问题 |
**已知问题：**  
Windows 原生通知适配尚未完善，可能出现报错或无法弹出系统通知的情况。建议仅作为无提醒功能的“纯日程看板”使用。
---
## 📦 编译与部署指南
### 前置要求
确保已安装：
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- 对应平台的构建工具（Android Studio / Xcode / Visual Studio 等）
### 构建 Release 版本
```bash
# Android
flutter build apk --release
# iOS
flutter build ios --release
# Linux
flutter build linux --release
# Windows
flutter build windows --release
```
生成的安装包位于：
```
build/
├── app/outputs/flutter-apk/app-release.apk   # Android
├── ios/iphoneos/Runner.app                   # iOS
├── linux/x64/release/bundle/                 # Linux
└── windows/runner/Release/                   # Windows
```
